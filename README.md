# Menaxhimi i Studentëve

## Seminar–Laboratori 1 – Inxhinieri Programesh

Aplikacion demonstrues për menaxhimin
e studentëve, i zhvilluar me HTML,
CSS dhe JavaScript.

## Objektivat

- Njohja me GitHub dhe StackBlitz
- Krijimi i strukturës së projektit
- Ndërtimi i ndërfaqes me HTML dhe CSS
- Programimi me JavaScript
- Menaxhimi i studentëve
- Ruajtja lokale e të dhënave
- Testimi dhe dokumentimi

## Funksionalitetet

- Regjistrimi i studentëve
- Modifikimi i studentëve
- Fshirja e studentëve
- Kërkimi sipas emrit
- Numërimi i studentëve
- Ruajtja me localStorage
- Validimi i emrave
- Parandalimi i regjistrimeve të dyfishta

## Teknologjitë

HTML5 – Struktura e aplikacionit

CSS3 – Dizajni dhe paraqitja

JavaScript – Logjika e aplikacionit

localStorage – Ruajtja lokale

GitHub – Versionimi i kodit

StackBlitz – Mjedisi i zhvillimit

## Ekzekutimi

1. Hapni projektin në StackBlitz.
2. Nisni serverin e zhvillimit.
3. Hapni Preview.
4. Testoni funksionalitetet.
